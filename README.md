# ShopKart

ShopKart is a simple React shopping page that displays different products in a product grid.

## Day 1 vs Day 2

### Day 1

On Day 1, I created the basic ShopKart layout and ProductCard components. The product cards were hardcoded.

### Day 2

On Day 2, I learned about props and used them to make ProductCard reusable. Product information is now stored in an array and displayed using map(). Each product has a unique key using its id.

I also added a SectionHeader component and fixed the product grid so the cards display side by side.
